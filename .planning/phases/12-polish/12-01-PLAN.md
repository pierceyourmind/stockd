<task type="auto">
  <name>Task 1: Add batchCreate backend endpoint</name>
  <files>modules/stocks.php, api.php</files>
  <action>
In modules/stocks.php, add a new function `batchCreateStocks(PDO $pdo): never` after the existing `deleteStock` function. The function should:

1. Read JSON body: `$input = json_decode(file_get_contents('php://input'), true)`
2. Extract `$symbols = $input['symbols'] ?? []` and `$account = $input['account'] ?? null`
3. Validate: if empty symbols array, return 400 error
4. Cap at 50 symbols max (return 400 if exceeded)
5. Wrap processing in `$pdo->beginTransaction()` / `$pdo->commit()` with catch for rollback
6. For each symbol:
   a. Trim, uppercase, validate format with `/^[A-Z]{1,5}$/` — if invalid, add to `$errors` array and skip
   b. Check if symbol already exists in stocks table (any account) — if so, add to `$skipped` array and skip
   c. Fetch company name from Yahoo Finance using the quoteSummary endpoint: `https://query1.finance.yahoo.com/v10/finance/quoteSummary/{symbol}?modules=price` — extract shortName or longName. Use the existing `yahooContext()` function from lib/yahoo.php for the stream context. Add 100ms delay between Yahoo calls (usleep(100000)) to respect rate limits.
   d. If Yahoo returns no data, use the symbol itself as company_name (still create the stock)
   e. Insert into stocks table as watchlist stock (is_watchlist=1) with the fetched company_name. If account is provided and not empty, set account and is_watchlist=0.
   f. Increment `$created` counter
7. After loop, commit transaction
8. Return JSON: `{ created: N, skipped: ['SYM1', 'SYM2'], errors: ['XYZ: invalid format'], total: count($symbols) }`

In api.php, add the route `'batchCreate' => batchCreateStocks($pdo),` to the match expression, after the existing 'delete' route.
  </action>
  <verify>
Run: `php -l modules/stocks.php && php -l api.php` to confirm no syntax errors.
Then test with curl:
`curl -s -b cookies.txt 'http://localhost:8080/api.php?action=batchCreate' -X POST -H 'Content-Type: application/json' -d '{"symbols":["AAPL","INVALIDTOOLONGSYMBOL","ZZZQ"]}'`
Should return JSON with created/skipped/errors counts.
  </verify>
  <done>
batchCreate endpoint accepts POST with symbols array, processes each in a transaction, returns detailed results with created/skipped/errors breakdown. Invalid symbols and duplicates handled gracefully without failing the entire batch.
  </done>
