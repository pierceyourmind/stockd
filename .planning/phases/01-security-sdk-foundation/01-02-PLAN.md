**api.php** -- Add WAL mode and new tables to the database setup section:
- Find the existing PDO initialization block (around lines 22-26 where `$pdo = new PDO(...)` is created)
- Immediately AFTER the PDO creation and BEFORE the existing `CREATE TABLE IF NOT EXISTS stocks` statement, add:
  ```php
  // Enable WAL mode for concurrent read/write access
  $pdo->exec('PRAGMA journal_mode=WAL');
  // Wait up to 5 seconds for locks instead of failing immediately
  $pdo->exec('PRAGMA busy_timeout=5000');
  ```
- After ALL existing table creation and migration statements (after the alerts table and all ALTER TABLE migrations), add the three new tables. Use CREATE TABLE IF NOT EXISTS so they are safe to re-run:

  **connections table:**
  ```sql
  CREATE TABLE IF NOT EXISTS connections (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      snaptrade_connection_id VARCHAR(100) UNIQUE NOT NULL,
      brokerage_name VARCHAR(100) NOT NULL,
      account_name VARCHAR(100),
      status VARCHAR(20) DEFAULT 'active',
      created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
      last_synced_at DATETIME
  )
  ```

  **positions table:**
  ```sql
  CREATE TABLE IF NOT EXISTS positions (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      connection_id INTEGER NOT NULL,
      security_id VARCHAR(100),
      cusip VARCHAR(20),
      symbol VARCHAR(20) NOT NULL,
      quantity DECIMAL(10,4) NOT NULL,
      average_purchase_price DECIMAL(10,2),
      current_price DECIMAL(10,2),
      cost_basis_source VARCHAR(20) DEFAULT 'brokerage',
      created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
      updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
      FOREIGN KEY (connection_id) REFERENCES connections(id) ON DELETE CASCADE
  )
  ```

  **sync_log table:**
  ```sql
  CREATE TABLE IF NOT EXISTS sync_log (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      connection_id INTEGER,
      status VARCHAR(20) NOT NULL,
      holdings_count INTEGER,
      error_message TEXT,
      synced_at DATETIME DEFAULT CURRENT_TIMESTAMP,
      FOREIGN KEY (connection_id) REFERENCES connections(id) ON DELETE SET NULL
  )
  ```

IMPORTANT: Do NOT modify any other part of api.php. Only add WAL pragmas after PDO creation and new tables after existing table/migration blocks.
