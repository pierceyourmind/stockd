Add a "Brokerage Connections" section to index.php. This involves changes to both the HTML structure and the Alpine.js `stockApp()` JavaScript.

**Alpine.js state additions (in the stockApp() function's data properties):**

Add these properties to the Alpine.js component data:
```javascript
brokerageConnections: [],     // Array of connection objects from API
brokerageAccounts: [],        // Array of account objects from API
connectionsLoading: false,    // Loading state for connections fetch
```

**Alpine.js methods (add to the stockApp() function):**

1. `loadBrokerageConnections()` method:
   - Set `this.connectionsLoading = true`
   - Fetch `api.php?action=snaptradeConnections`, parse JSON, assign to `this.brokerageConnections`
   - Fetch `api.php?action=snaptradeAccounts`, parse JSON, assign to `this.brokerageAccounts`
   - Set `this.connectionsLoading = false`
   - Wrap both fetches in try/catch; on error, show toast with `this.showToast('Failed to load connections', 'error')`

2. `connectBrokerage()` method:
   - Simply redirect: `window.location.href = 'api.php?action=snaptradeConnect'`
   - This is NOT a fetch call -- it's a full-page redirect because the user needs to leave the app and go to SnapTrade's portal.

3. `reconnectBrokerage(connectionId)` method:
   - Redirect: `window.location.href = 'api.php?action=snaptradeConnect&reconnect=' + encodeURIComponent(connectionId)`

4. `deleteBrokerageConnection(connectionId)` -- defer to Phase 4 (do NOT implement). No delete functionality in this phase.

**Init hook update:**

In the `init()` method (or `$nextTick` callback), add a call to `this.loadBrokerageConnections()` so connections load on page startup.

Also in `init()`, check URL parameters for OAuth result messaging:
```javascript
const urlParams = new URLSearchParams(window.location.search);
if (urlParams.get('connected') === 'success') {
    this.showToast('Brokerage connected successfully!', 'success');
    // Clean URL
    window.history.replaceState({}, document.title, '/');
    // Reload connections to show new one
    this.loadBrokerageConnections();
}
if (urlParams.get('error')) {
    const errorMap = {
        'connection_failed': 'Failed to connect brokerage. Please try again.',
        'csrf_failed': 'Security validation failed. Please try again.',
        'no_snaptrade_user': 'SnapTrade user not configured. Check your .env file.',
        'storage_failed': 'Failed to save connection data. Please try again.'
    };
    const msg = errorMap[urlParams.get('error')] || 'An error occurred. Please try again.';
    this.showToast(msg, 'error');
    window.history.replaceState({}, document.title, '/');
}
```
