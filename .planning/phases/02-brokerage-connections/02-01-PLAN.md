**Database schema additions in api.php (in the schema initialization section after the sync_log table):**

1. Create `snaptrade_users` table (stores the single SnapTrade user registration):
```sql
CREATE TABLE IF NOT EXISTS snaptrade_users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    snaptrade_user_id VARCHAR(100) UNIQUE NOT NULL,
    user_secret VARCHAR(255) NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
)
```

2. Create `accounts` table (sub-accounts under connections -- 401k, IRA, individual, etc.):
```sql
CREATE TABLE IF NOT EXISTS accounts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    connection_id INTEGER NOT NULL,
    snaptrade_account_id VARCHAR(100) UNIQUE NOT NULL,
    name VARCHAR(100),
    account_number VARCHAR(50),
    institution_name VARCHAR(100),
    balance_amount DECIMAL(10,2),
    balance_currency VARCHAR(10) DEFAULT 'USD',
    status VARCHAR(20) DEFAULT 'open',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (connection_id) REFERENCES connections(id) ON DELETE CASCADE
)
```

**New API endpoints (add to the match statement in api.php):**

3. `snaptradeConnect` action -- Registers SnapTrade user (if not already registered), generates Connection Portal URL, and redirects:
   - Load SnapTrade user from `snaptrade_users` table. If none exists, call `$snaptrade->authentication->registerSnapTradeUser(['userId' => $snaptradeUserId])` where `$snaptradeUserId` is read from `$_ENV['SNAPTRADE_USER_ID']` (e.g., 'stockd-user-1'). Store the returned `userSecret` in `snaptrade_users` table.
   - Generate CSRF state token: `$state = bin2hex(random_bytes(32))`, store in `$_SESSION['snaptrade_oauth_state'] = $state`.
   - Call `$snaptrade->authentication->loginSnapTradeUser(userId: $snaptradeUserId, userSecret: $userSecret, immediateRedirect: true, customRedirect: $callbackUrl, connectionType: 'read')` where `$callbackUrl` is constructed from `$_ENV['APP_URL']` + '/auth/snaptrade_callback.php?state=' + $state.
   - Instead of returning JSON, redirect the user: `header('Location: ' . $portal['redirectURI']); exit;` -- this is a redirect endpoint, NOT a JSON API.
   - If `$_GET['reconnect']` is provided, pass it as the `reconnect` parameter to `loginSnapTradeUser` to handle disabled connection re-auth.
   - Wrap in try/catch; on error, redirect to index.php with `?error=connection_failed` query param.

4. `snaptradeConnections` action -- Lists all stored connections with their status:
   - Query `connections` table: `SELECT * FROM connections ORDER BY created_at DESC`
   - Also check live status by calling `$snaptrade->connections->listBrokerageAuthorizations(userId, userSecret)` and updating `status` to 'disabled' for any connection where `disabled === true`. Use a simple loop with UPDATE statement.
   - Return JSON array of connections.
   - If no SnapTrade user exists (no row in snaptrade_users), return empty array (not an error).

5. `snaptradeAccounts` action -- Lists all sub-accounts:
   - Query: `SELECT a.*, c.brokerage_name, c.status as connection_status FROM accounts a JOIN connections c ON a.connection_id = c.id ORDER BY c.brokerage_name, a.name`
   - Return JSON array of accounts with their parent connection info.

**Helper:** Create a `getSnapTradeClient()` helper function near the top of api.php (after jsonResponse) that initializes and returns the SnapTrade client:
```php
function getSnapTradeClient(): \SnapTrade\Client {
    return new \SnapTrade\Client(
        clientId: $_ENV['SNAPTRADE_CLIENT_ID'],
        consumerKey: $_ENV['SNAPTRADE_CONSUMER_KEY']
    );
}
```

Also create a `getSnapTradeUser(PDO $pdo): ?array` helper that queries the snaptrade_users table and returns `['user_id' => ..., 'user_secret' => ...]` or null.

<task type="auto">
  <name>Task 2: Create OAuth callback handler with CSRF validation and connection/account storage</name>
  <files>auth/snaptrade_callback.php</files>
  <action>
Create `auth/snaptrade_callback.php` -- the redirect target after SnapTrade Connection Portal completes.

**File structure:**

1. Require bootstrap.php and auth/session.php (for session access and authentication check).
2. Call `requireAuth()` to ensure only authenticated users can process callbacks.
3. Validate CSRF state parameter:
   - Get `$returnedState = $_GET['state'] ?? ''`
   - Get `$expectedState = $_SESSION['snaptrade_oauth_state'] ?? ''`
   - If either is empty OR `!hash_equals($expectedState, $returnedState)`, redirect to `/?error=csrf_failed` and exit.
   - Clear the used state: `unset($_SESSION['snaptrade_oauth_state'])`

4. Initialize SnapTrade client and load user credentials:
   - Require bootstrap.php for autoloading.
   - Open the database: `$pdo = new PDO('sqlite:' . __DIR__ . '/../db/stocks.db', ...)` with the same options as api.php (ERRMODE_EXCEPTION, FETCH_ASSOC). Enable WAL mode + busy_timeout.
   - Query snaptrade_users table for userId and userSecret. If not found, redirect to `/?error=no_snaptrade_user`.
   - Create SnapTrade client.

5. Fetch connections and accounts from SnapTrade API:
   - Call `$snaptrade->connections->listBrokerageAuthorizations(userId: $userId, userSecret: $userSecret)` to get all connections.
   - Call `$snaptrade->accountInformation->listUserAccounts(userId: $userId, userSecret: $userSecret)` to get all sub-accounts.

6. Store connections and accounts in a PDO transaction:
   - `$pdo->beginTransaction()`
   - For each connection: `INSERT OR REPLACE INTO connections (snaptrade_connection_id, brokerage_name, status, last_synced_at) VALUES (?, ?, ?, CURRENT_TIMESTAMP)` using the connection's `id`, `brokerage.name` (or `brokerage['name']`), and status (`disabled` field -> 'disabled' or 'active').
   - For each account: First find the connection_id from the connections table using the account's `brokerage_authorization` field. Then `INSERT OR REPLACE INTO accounts (connection_id, snaptrade_account_id, name, account_number, institution_name, balance_amount, balance_currency, status) VALUES (?, ?, ?, ?, ?, ?, ?, ?)`. Use safe null coalescing for optional fields.
   - `$pdo->commit()`
   - On exception: `$pdo->rollBack()`, redirect to `/?error=storage_failed`.

7. Redirect to success: `header('Location: /?connected=success'); exit;`

**Important implementation notes:**
- The SnapTrade SDK returns objects or arrays depending on the method. Access connection fields like: `$conn->getId()` or `$conn['id']`. Check the actual SDK return types -- the PHP SDK may return model objects with getter methods. Wrap in a try/catch and access either way. If the SDK returns model objects, use `$conn->getId()`, `$conn->getBrokerage()->getName()`, `$conn->getDisabled()`. If arrays, use bracket notation.
- For account balance, access `$account->getBalance()` which may return a Balance object with `getAmount()` and `getCurrency()` methods, or it may be null.
- The `brokerage_authorization` field on an account links it to a connection by the connection's SnapTrade UUID (snaptrade_connection_id).
- Use `INSERT OR REPLACE` (SQLite UPSERT) to handle re-running the callback idempotently. This requires the UNIQUE constraint on `snaptrade_connection_id` and `snaptrade_account_id` columns.
- Do NOT use `account_name` column in connections table for storing brokerage name -- that column is for the account name. Use `brokerage_name` column.
