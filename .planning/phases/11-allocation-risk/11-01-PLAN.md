<task type="auto">
  <name>Task 2: Four allocation/risk/income API endpoints</name>
  <files>modules/analytics.php, api.php</files>
  <action>
Add four new functions to the END of `modules/analytics.php` (after `getPerformanceRankings`). All follow the established pattern: accept `PDO $pdo`, return `never`, use `jsonResponse()`.

**CRITICAL: The stocks table has NO `current_price` or `dividend_yield` column.** All prices must be fetched from Yahoo Finance at request time using the batch spark endpoint, exactly like `getPerformanceRankings()` does.

**Endpoint 1: `getSectorAllocation(PDO $pdo): never`**
- Query active holdings: `SELECT DISTINCT symbol, SUM(shares) as total_shares FROM stocks WHERE is_watchlist = 0 AND removed_flag = 0 AND shares > 0 GROUP BY symbol`
- Batch fetch current prices using Yahoo spark endpoint (same pattern as `getPerformanceRankings`): `https://query1.finance.yahoo.com/v8/finance/spark?symbols={csv}&range=1d&interval=1d`
- Query sector_cache with 30-day TTL: `SELECT symbol, sector FROM sector_cache WHERE cached_at > ? ORDER BY cached_at DESC`
- Deduplicate cache by symbol (take latest per symbol, same as `getSectors`)
- Calculate portfolio value per sector: group by `COALESCE(sector, 'Unknown')`, sum `shares * currentPrice`
- Calculate total portfolio value, then percentage for each sector: `100.0 * sectorValue / totalValue`
- Filter to only EQUITY stocks for sector chart (ETFs get sector data from Yahoo but belong in asset class chart, not sector). To detect ETFs, check asset_type_cache with 30-day TTL. If no cache entry for a symbol, include it in sector chart (assume equity by default; asset class endpoint handles classification)
- Return: `jsonResponse(['sectors' => [...], 'total_value' => $total])` where each sector has `{sector, value, percentage}`
- Sort by value descending
- Handle division by zero: if total portfolio value is 0, return empty sectors array

**Endpoint 2: `getAssetClassAllocation(PDO $pdo): never`**
- Query active holdings (same as above with SUM shares GROUP BY symbol)
- Batch fetch current prices from Yahoo spark (same pattern)
- For each symbol, check `asset_type_cache` (30-day TTL). If cache miss, call `fetchAssetType($symbol)` from yahoo.php, store result in `asset_type_cache`, add 500ms delay (`usleep(500000)`)
- Map quoteType to display names: `'EQUITY' => 'Stocks'`, `'ETF' => 'ETFs'`, `'MUTUALFUND' => 'Mutual Funds'`, `default => 'Other'`
- Group by asset class, calculate value and percentage (same pattern as sector)
- Return: `jsonResponse(['asset_classes' => [...], 'total_value' => $total])` where each has `{asset_class, value, percentage}`
- Sort by value descending

**Endpoint 3: `getConcentrationRisk(PDO $pdo): never`**
- Query active holdings (same GROUP BY symbol pattern)
- Batch fetch current prices from Yahoo spark
- Calculate total portfolio value
- Check each position: if `(positionValue / totalValue) * 100 > 25`, add position warning
- Check each sector: reuse sector allocation logic, if `sectorPercentage > 40`, add sector warning
- Use sector_cache with 30-day TTL for sector grouping
- Return: `jsonResponse(['warnings' => [...], 'total_value' => $total])` where each warning has `{type: 'position'|'sector', name, value, percentage, threshold}`
- Handle edge case: if total value is 0, return empty warnings

**Endpoint 4: `getDividendIncome(PDO $pdo): never`**
- Query active holdings with shares > 0 (GROUP BY symbol, SUM shares)
- Batch fetch current prices AND dividend yield from Yahoo. Use the `v8/finance/chart/{symbol}?interval=1d&range=1y&events=div` endpoint per-stock (same as `getDividends` in dividends.php) to get trailing 12-month dividend sum. Rate limit at 100ms between calls.
- For each stock: `annual_income = shares * trailing_12m_dividend_sum` (sum of all dividend events in last 12 months times shares)
- This is more accurate than `shares * price * yield / 100` because yield can be stale
- Join with sector_cache for sector breakdown
- Return: `jsonResponse(['total_annual' => round($total, 2), 'by_sector' => [...], 'by_stock' => [...], 'dividend_stock_count' => $count, 'total_stock_count' => $totalStocks])`
- `by_sector`: array of `{sector, annual_income, percentage}` sorted by income descending
- `by_stock`: array of `{symbol, company_name, shares, annual_dividend_per_share, annual_income}` sorted by income descending
- Filter: only include stocks that actually pay dividends (have dividend events in last 12 months)

**Add routes in `api.php`** — add 4 entries to the match statement before the `default` case:

