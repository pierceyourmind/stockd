- If closing, destroys both chart instances (same pattern as `toggleAnalytics` destroys `historicalChart`)

**4. Data loading method `loadAllocationData()`:**
- Sets `this.allocationLoading = true`
- Fetches all 4 endpoints in parallel using `Promise.all`:
  - `api.php?action=sectorAllocation`
  - `api.php?action=assetClassAllocation`
  - `api.php?action=concentrationRisk`
  - `api.php?action=dividendIncome`
- Stores results: `this.sectorData`, `this.assetClassData`, `this.concentrationWarnings`, `this.dividendIncome`
- Calls `this.renderSectorChart()` and `this.renderAssetClassChart()` via `this.$nextTick()`
- Sets `this.allocationLoading = false`
- Wraps in try/catch with `this.showToast('Failed to load allocation data', 'error')`

**5. Chart rendering methods:**

`renderSectorChart()`:
- Destroy existing: `if (sectorAllocationChart) { sectorAllocationChart.destroy(); sectorAllocationChart = null; }`
- Get canvas: `document.getElementById('sector-allocation-chart')`
- Guard: `if (!canvas || !this.sectorData.length) return;`
- Reuse the EXACT same color palette from `renderPortfolioCharts()` (line 2853): `['#58a6ff', '#3fb950', '#f85149', '#a371f7', '#f0883e', '#56d4dd', '#db61a2', '#7ee787', '#79c0ff', '#ffa657']`
- Labels: `sectors.map(s => s.sector + ' ' + s.percentage.toFixed(1) + '%')`
- Data: `sectors.map(s => s.value)`
- Chart type: `'doughnut'`
- Options: match existing doughnut chart options exactly (responsive, maintainAspectRatio false, legend right with color #8b949e font size 11 boxWidth 12 padding 8, tooltip with dark background and dollar formatting with percentage)

`renderAssetClassChart()`:
- Same destroy/guard/color/options pattern as sector chart but using `assetClassChart` variable and `asset-class-chart` canvas ID
- Labels: `assetClasses.map(a => a.asset_class + ' ' + a.percentage.toFixed(1) + '%')`
- Data: `assetClasses.map(a => a.value)`

**6. Helper formatting:**
Add a method `formatCurrency(value)` that returns `'$' + value.toLocaleString('en-US', {minimumFractionDigits: 2, maximumFractionDigits: 2})`. Use this in the HTML template for income amounts.
