**Function: `fetchSectorData(string $symbol): array`**

This is a standalone utility that fetches sector/industry data from Yahoo Finance for a single symbol. It does NOT handle caching (that's the caller's responsibility). It does NOT add rate limiting delays (that's the caller's responsibility in the loop).

Logic:
1. Build URL: `https://query1.finance.yahoo.com/v11/finance/quoteSummary/{symbol}?modules=assetProfile`
   - Use `urlencode($symbol)` for the symbol.
   - Note: This is the v11 quoteSummary endpoint, NOT the v8 chart endpoint used elsewhere.
2. Create context with `yahooContext()`.
3. Fetch with `@file_get_contents($url, false, $context)`.
4. If fetch fails (returns false), return `['sector' => null, 'industry' => null, 'error' => true]`.
5. Decode JSON response.
6. Extract assetProfile: `$data['quoteSummary']['result'][0]['assetProfile'] ?? null`
7. If no assetProfile found, return `['sector' => null, 'industry' => null, 'error' => false]`.
8. Extract sector and industry: `$profile['sector'] ?? null` and `$profile['industry'] ?? null`.
9. Return `['sector' => $sector, 'industry' => $industry, 'error' => false]`.

Keep the function simple and pure — fetch + parse + return. No database, no caching, no delays.

**Function 1: `enrichSectors(PDO $pdo): never`**

Fetches and caches sector data for all portfolio holdings that don't have valid (non-expired) cache entries.

Logic:
1. Get all unique symbols from active holdings:
   ```sql
   SELECT DISTINCT symbol FROM stocks WHERE is_watchlist = 0 AND removed_flag = 0
   ```
2. Define TTL: `$thirtyDaysAgo = time() - (30 * 24 * 60 * 60);`
3. For each symbol, check if valid cache exists:
   ```sql
   SELECT sector, industry FROM sector_cache WHERE symbol = ? AND cached_at > ? ORDER BY cached_at DESC LIMIT 1
   ```
4. If cached entry exists and is not expired, skip this symbol (add to `$results` with `'cached' => true`).
5. If no valid cache, call `fetchSectorData($symbol)` from lib/yahoo.php.
6. If fetch succeeded (error !== true), insert into sector_cache:
   ```sql
   INSERT INTO sector_cache (symbol, sector, industry, cached_at) VALUES (?, ?, ?, ?)
   ```
   Use `time()` for cached_at.
7. Add to `$results` array with sector, industry, and `'cached' => false`.
8. **Rate limiting: `usleep(500000)` (500ms) after EACH Yahoo Finance request** — this is critical to prevent IP bans. Only delay after actual API calls, not cache hits. Research says 500ms-1s; use 500ms as baseline.
9. Track counts: `$fetched` (API calls made), `$cached` (cache hits), `$failed` (fetch errors).
10. Return `jsonResponse(['results' => $results, 'fetched' => $fetched, 'cached' => $cached, 'failed' => $failed])`.

**Function 2: `getSectors(PDO $pdo): never`**

Returns cached sector data for all holdings (for use by Phase 11 allocation charts).

Logic:
1. Query sector data joined with stocks to get only relevant symbols:
   ```sql
   SELECT DISTINCT s.symbol, sc.sector, sc.industry, sc.cached_at
   FROM stocks s
   LEFT JOIN sector_cache sc ON s.symbol = sc.symbol
       AND sc.cached_at > ?
       AND sc.id = (SELECT MAX(id) FROM sector_cache sc2 WHERE sc2.symbol = s.symbol AND sc2.cached_at > ?)
   WHERE s.is_watchlist = 0 AND s.removed_flag = 0
   ORDER BY s.symbol
   ```
   Pass `$thirtyDaysAgo` for both `?` parameters.

   Alternatively, keep it simpler — two queries:
   a. Get distinct symbols from stocks.
   b. For each symbol, get most recent non-expired sector_cache entry.

   Use the simpler approach: query all symbols, then batch-fetch their cache entries:
   ```sql
   SELECT symbol, sector, industry, cached_at
   FROM sector_cache
   WHERE cached_at > ?
   ORDER BY cached_at DESC
   ```
   Then deduplicate by symbol in PHP (take first/latest entry per symbol). Map the results by symbol.

2. Get active holdings symbols:
   ```sql
   SELECT DISTINCT symbol FROM stocks WHERE is_watchlist = 0 AND removed_flag = 0 ORDER BY symbol
   ```

3. Build result array mapping each symbol to its sector/industry (or null if not cached).

4. Return `jsonResponse(['sectors' => $results])`.

**api.php** — Add two new routes to the match() expression:
```php

'sectors' => getSectors($pdo),
```
