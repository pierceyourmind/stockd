**portfolio_snapshots table:**
```sql
CREATE TABLE IF NOT EXISTS portfolio_snapshots (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    snapshot_date INTEGER NOT NULL,
    total_value DECIMAL(12,2) NOT NULL,
    stock_count INTEGER NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
)
```
- snapshot_date is INTEGER (Unix timestamp for midnight of snapshot day) — NOT text date. Integer timestamps are 3x faster for sorting/comparison per research.
- Create unique index: `CREATE UNIQUE INDEX IF NOT EXISTS idx_snapshot_date ON portfolio_snapshots(snapshot_date)`

**sector_cache table:**
```sql
CREATE TABLE IF NOT EXISTS sector_cache (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    symbol VARCHAR(10) NOT NULL,
    sector VARCHAR(100),
    industry VARCHAR(100),
    cached_at INTEGER NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
)
```
- cached_at is INTEGER (Unix timestamp) for efficient 30-day TTL math via integer subtraction.
- sector and industry are nullable — Yahoo Finance returns NULL for some stocks.
- Create indexes: `CREATE INDEX IF NOT EXISTS idx_sector_symbol ON sector_cache(symbol)` and `CREATE INDEX IF NOT EXISTS idx_sector_cached_at ON sector_cache(cached_at)`

Use IF NOT EXISTS on both tables AND indexes to be idempotent (matches existing migration pattern in database.php).

**Function 1: `generateSnapshot(PDO $pdo): never`**

This endpoint is called by the frontend on page load to ensure today's snapshot exists.

Logic:
1. Calculate today's midnight timestamp: `$snapshotDate = strtotime('today midnight');`
2. Check if today's snapshot already exists:
   ```sql
   SELECT id FROM portfolio_snapshots WHERE snapshot_date = ?
   ```
   If exists, return `jsonResponse(['status' => 'exists', 'message' => 'Today snapshot already exists'])`.
3. If missing, calculate portfolio total market value:
   - Query all active holdings: `SELECT symbol, shares FROM stocks WHERE is_watchlist = 0 AND removed_flag = 0 AND shares > 0`
   - For each stock, fetch current price from Yahoo Finance using the v8 chart endpoint (same pattern as quotes.php getQuote): `https://query1.finance.yahoo.com/v8/finance/chart/{symbol}?interval=1d&range=1d`
   - Extract `regularMarketPrice` from `meta` in the response.
   - Calculate: total_value = SUM(shares * currentPrice) for all holdings.
   - Add usleep(100000) between Yahoo requests (100ms, matching existing dividends.php pattern — this is for the quick price fetch, not sector data which needs longer delays).
   - If a Yahoo fetch fails for a symbol, use purchase_price as fallback: also fetch purchase_price in the initial query.
4. Count stocks: the number of holdings queried.
5. UPSERT the snapshot:
   ```sql
   INSERT INTO portfolio_snapshots (snapshot_date, total_value, stock_count)
   VALUES (?, ?, ?)
   ON CONFLICT(snapshot_date)
   DO UPDATE SET
       total_value = excluded.total_value,
       stock_count = excluded.stock_count,
       updated_at = CURRENT_TIMESTAMP
   ```
6. Return `jsonResponse(['status' => 'created', 'snapshot_date' => $snapshotDate, 'total_value' => $totalValue, 'stock_count' => $stockCount])`.

**Function 2: `getSnapshots(PDO $pdo): never`**

Returns snapshot history for charting (used by Phase 10).

Logic:
1. Read optional `days` parameter: `$days = (int) ($_GET['days'] ?? 90);` Clamp to 1-365.
2. Calculate start date: `$startDate = time() - ($days * 86400);`
3. Query:
   ```sql
   SELECT snapshot_date, total_value, stock_count, created_at
   FROM portfolio_snapshots
   WHERE snapshot_date >= ?
   ORDER BY snapshot_date ASC
   ```
4. Return `jsonResponse(['snapshots' => $results, 'days' => $days])`.
