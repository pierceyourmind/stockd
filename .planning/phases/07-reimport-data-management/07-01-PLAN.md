Re-import diff engine that detects stocks removed between CSV uploads, flags them for user review, and provides confirm/dismiss actions.

Purpose: When users re-upload a CSV to refresh their portfolio, stocks that disappeared from the new export need to be surfaced for review rather than silently kept or auto-deleted. This completes the re-import workflow.

Output: Modified api.php with diff detection and flag management endpoints, modified index.php with flagged stock visual indicators and action buttons.
</objective>

2. **Modify importCSV() function to detect and flag missing stocks**:

   a. Build an imported-symbols-per-account map during the upsert loop. Add `$importedByAccount = [];` at initialization (alongside $created, $updated, $accounts). Inside the foreach loop, after tracking accounts, add:
   ```php
   if (!isset($importedByAccount[$account])) {
       $importedByAccount[$account] = [];
   }
   $importedByAccount[$account][] = $symbol;
   ```

   b. During the upsert UPDATE branch (existing stock), also clear removed_flag:
   Change `SET company_name = ?, shares = ?, purchase_price = ?, updated_at = CURRENT_TIMESTAMP`
   to `SET company_name = ?, shares = ?, purchase_price = ?, removed_flag = 0, updated_at = CURRENT_TIMESTAMP`

   c. After `$pdo->commit()` (around line 621), add diff detection logic:
   ```php
   // Flag stocks missing from re-import
   $flagged = 0;
   foreach ($importedByAccount as $acct => $symbols) {
       $placeholders = implode(',', array_fill(0, count($symbols), '?'));
       $stmt = $pdo->prepare("
           UPDATE stocks
           SET removed_flag = 1, updated_at = CURRENT_TIMESTAMP
           WHERE account = ?
             AND symbol NOT IN ($placeholders)
             AND is_watchlist = 0
             AND removed_flag = 0
       ");
       $stmt->execute(array_merge([$acct], $symbols));
       $flagged += $stmt->rowCount();
   }
   ```

   d. Add `'flagged' => $flagged` to the import response array (alongside created, updated, skipped, total_holdings, accounts).

3. **Add two new endpoint functions and routes**:

   Add to the match statement (around line 412):
   ```php
   'dismissFlag' => dismissFlag($pdo),
   'confirmRemoval' => confirmRemoval($pdo),
   ```

   **dismissFlag function** (add after importCSV function):
   - Gets stock ID from `$_GET['id']`
   - Validates ID > 0
   - Runs: `UPDATE stocks SET removed_flag = 0, updated_at = CURRENT_TIMESTAMP WHERE id = ?`
   - Returns 404 if rowCount is 0
   - Returns success JSON with message

   **confirmRemoval function** (add after dismissFlag):
   - Gets stock ID from `$_GET['id']`
   - Validates ID > 0
   - Runs: `DELETE FROM stocks WHERE id = ? AND removed_flag = 1`
   - Returns 404 if rowCount is 0 (stock not found or not flagged)
   - Returns success JSON with message
  </action>
