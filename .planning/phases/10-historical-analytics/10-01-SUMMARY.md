## Decisions Made

**1. O(symbols) efficiency pattern**
- Fetch all historical prices first (one Yahoo call per symbol), build price map, then iterate dates
- Prevents O(symbols * dates) API explosion (would be 90x more calls)
- Rationale: Yahoo Finance rate limiting makes this essential for portfolios with many holdings

**2. ON CONFLICT DO NOTHING for backfill**
- Preserves real-time snapshots generated by generateSnapshot() over backfilled historical data
- Does not use UPSERT/DO UPDATE to avoid overwriting existing snapshots
- Rationale: Real-time prices are more accurate than historical backfill fallbacks

**3. YTD uses January 1 of current year**
- Implemented as `strtotime('first day of January this year midnight')`
- Not 365 days ago (which would be rolling 1-year return)
- Rationale: Standard financial definition of YTD return

**4. Rankings sorted by gain_loss_pct descending**
- Best performers appear first in rankings array
- Rationale: Most common use case is identifying top/bottom performers
