<task type="auto">
  <name>Task 1: Add fetchHistoricalPrices utility and backfill endpoint</name>
  <files>lib/yahoo.php, modules/analytics.php, api.php</files>
  <action>
1. In lib/yahoo.php, add a `fetchHistoricalPrices(string $symbol, int $days = 90): array` function:
   - Calculate period1 = time() - ($days * 86400) and period2 = time() as Unix timestamps (seconds)
   - Build URL: `https://query1.finance.yahoo.com/v8/finance/chart/{symbol}?period1={period1}&period2={period2}&interval=1d`
   - Use yahooContext() for HTTP context (already exists in yahoo.php)
   - Parse response: extract timestamps from `$result['timestamp']` and close prices from `$result['indicators']['quote'][0]['close']`
   - Skip null close prices (weekend/holiday gaps)
   - Return `['error' => false, 'prices' => [['date' => $ts, 'close' => (float)$close], ...]]` on success
   - Return `['error' => true, 'prices' => []]` on failure
   - Do NOT add rate limiting inside this function (caller handles rate limiting)

2. In modules/analytics.php, add `backfillSnapshots(PDO $pdo): never` function:
   - Get all active holdings: `SELECT DISTINCT symbol, shares, purchase_price FROM stocks WHERE is_watchlist = 0 AND removed_flag = 0 AND shares > 0`
   - For each unique symbol, call fetchHistoricalPrices($symbol, 90) with 100ms rate limiting (usleep(100000)) between calls
   - Build a price map: `$priceMap[$symbol][$normalizedDate] = $closePrice` where normalizedDate = `strtotime('midnight', $ts)` to normalize to midnight timestamps
   - Generate daily midnight timestamps for the last 90 days: loop from strtotime('90 days ago midnight') to strtotime('today midnight') in 86400-second steps
   - For each date, skip if snapshot already exists: `SELECT id FROM portfolio_snapshots WHERE snapshot_date = ?`
   - For each date, calculate total portfolio value by summing (shares * price) for each holding, using priceMap lookup with fallback to purchase_price if no historical price available
   - INSERT each new snapshot: `INSERT INTO portfolio_snapshots (snapshot_date, total_value, stock_count) VALUES (?, ?, ?) ON CONFLICT(snapshot_date) DO NOTHING`
   - Use ON CONFLICT DO NOTHING (not UPSERT) since we don't want to overwrite existing snapshots that used real-time prices
   - Track count of backfilled snapshots and any dates with fallback usage
   - Return JSON: `{backfilled: N, skipped: M, total_dates: 90, message: "Backfilled N snapshots"}`
   - IMPORTANT: Fetch all prices FIRST (one Yahoo call per symbol with rate limiting), THEN calculate snapshots for all dates. This is O(symbols) Yahoo calls, not O(symbols * dates).

3. Wire route in api.php: Add `'backfill' => backfillSnapshots($pdo)` to the match() expression (after the existing 'snapshots' route).

<task type="auto">
  <name>Task 2: Add returns calculation and performance rankings endpoints</name>
  <files>modules/analytics.php, api.php</files>
  <action>
1. In modules/analytics.php, add `getReturns(PDO $pdo): never` function:
   - Define time ranges as Unix timestamps:
     - '1w': time() - (7 * 86400)
     - '1m': time() - (30 * 86400)
     - 'ytd': strtotime('first day of January this year midnight') -- NOT 365 days ago
     - 'all': 0
   - For each range, query the EARLIEST snapshot at or after the start date:
     `SELECT total_value FROM portfolio_snapshots WHERE snapshot_date >= ? ORDER BY snapshot_date ASC LIMIT 1`
   - Query the LATEST snapshot overall:
     `SELECT total_value FROM portfolio_snapshots ORDER BY snapshot_date DESC LIMIT 1`
   - Calculate simple return: ((end_value - start_value) / start_value) * 100, rounded to 2 decimals
   - If start or end snapshot missing for a range, return null for that range
   - Handle zero start_value (return 0.0 to avoid division by zero)
   - Return JSON: `{returns: {1w: 2.5, 1m: -1.3, ytd: 5.7, all: 12.4}, latest_value: 50000.00, disclaimer: "Price return only. Does not include dividends, fees, or the effect of deposits/withdrawals. For tax reporting, use your broker statements."}`

2. In modules/analytics.php, add `getPerformanceRankings(PDO $pdo): never` function:
   - Query all active holdings with cost basis:
     `SELECT symbol, company_name, shares, purchase_price FROM stocks WHERE is_watchlist = 0 AND removed_flag = 0 AND shares > 0 AND purchase_price IS NOT NULL AND purchase_price > 0`
   - For each holding, fetch current price from Yahoo Finance using the same pattern as generateSnapshot:
     URL: `https://query1.finance.yahoo.com/v8/finance/chart/{symbol}?interval=1d&range=1d`
     Extract: `$data['chart']['result'][0]['meta']['regularMarketPrice']`
   - Calculate gain_loss_pct: ((current_price - purchase_price) / purchase_price) * 100, rounded to 2 decimals
   - Calculate gain_loss_amount: (current_price - purchase_price) * shares, rounded to 2 decimals
   - Calculate total_value: current_price * shares, rounded to 2 decimals
   - Rate limit: usleep(100000) between Yahoo requests (100ms, matching existing pattern)
   - Skip stocks where Yahoo fetch fails (don't include in rankings)
   - Sort by gain_loss_pct descending (best performers first)
   - Return JSON: `{rankings: [{symbol, company_name, cost_basis, current_price, shares, gain_loss_pct, gain_loss_amount, total_value}, ...]}`

3. Wire both routes in api.php match() expression:
   - Add `'returns' => getReturns($pdo)`
   - Add `'rankings' => getPerformanceRankings($pdo)`
   - Place after the 'backfill' route added in Task 1
  </action>
