**Chart Instance Variable (before the stockApp function, outside Alpine reactive scope):**
Add `let historicalChart = null;` before the `function stockApp()` declaration. This prevents Chart.js memory leaks per research -- Chart.js instances must NOT be stored inside Alpine reactive data.

**Alpine.js State Properties (inside stockApp() return object):**
Add these properties to the data object:
- `showAnalytics: false` - toggle for analytics section visibility
- `historicalSnapshots: []` - raw snapshot data from API
- `dateRange: 'all'` - currently selected date range (1w, 1m, ytd, all)
- `returns: {}` - return percentages by period
- `latestValue: null` - latest portfolio value from returns endpoint
- `returnDisclaimer: ''` - disclaimer text from returns endpoint
- `performanceRankings: []` - sorted stock rankings
- `backfillStatus: null` - status message from backfill ('loading', 'done', or null)
- `analyticsLoading: false` - loading state for analytics data

**Alpine.js Methods (inside stockApp() return object):**

1. `async toggleAnalytics()` method:
   - Toggle `this.showAnalytics`
   - If showing, call `this.$nextTick(() => { this.loadAnalyticsData(); })`
   - If hiding and historicalChart exists, destroy it and set to null

2. `async loadAnalyticsData()` method:
   - Set `this.analyticsLoading = true`
   - Fetch snapshots: `api.php?action=snapshots&days=365` -- store in `this.historicalSnapshots`
   - Fetch returns: `api.php?action=returns` -- store returns, latestValue, disclaimer
   - Fetch rankings: `api.php?action=rankings` -- store in `this.performanceRankings`
   - Call `this.renderHistoricalChart()` after data loads
   - Set `this.analyticsLoading = false`
   - Wrap in try/catch, show toast on error

3. `filteredSnapshots()` method (not a getter -- called explicitly):
   - Filter `this.historicalSnapshots` based on `this.dateRange`
   - Date ranges in milliseconds:
     - '1w': Date.now() - (7 * 86400000)
     - '1m': Date.now() - (30 * 86400000)
     - 'ytd': new Date(new Date().getFullYear(), 0, 1).getTime()  -- Jan 1 current year
     - 'all': 0
   - Filter: `this.historicalSnapshots.filter(s => (s.snapshot_date * 1000) >= cutoff)`
   - CRITICAL: Multiply snapshot_date by 1000 (PHP seconds to JS milliseconds)

4. `renderHistoricalChart()` method:
   - If historicalChart exists, destroy it (historicalChart.destroy(); historicalChart = null;)
   - Get canvas: `document.getElementById('historical-chart')`
   - If no canvas, return
   - Map filtered snapshots to Chart.js data points: `{ x: s.snapshot_date * 1000, y: parseFloat(s.total_value) }`
   - Create new Chart with config:
     - type: 'line'
     - dataset: label 'Portfolio Value', borderColor '#58a6ff', backgroundColor 'rgba(88,166,255,0.1)', fill true, tension 0.1, pointRadius 0, pointHoverRadius 4, borderWidth 2
     - options.parsing: false (performance -- data already in internal format)
     - options.normalized: true
     - options.responsive: true, maintainAspectRatio: false
     - x scale: type 'time', time.unit 'day', time.displayFormats.day 'MMM D', grid color 'rgba(255,255,255,0.05)', ticks color '#8b949e'
     - y scale: grid color 'rgba(255,255,255,0.05)', ticks color '#8b949e', ticks.callback: (v) => '$' + v.toLocaleString()
     - plugins.legend.display: false
     - plugins.tooltip: mode 'index', intersect false, backgroundColor 'rgba(22,27,34,0.9)', titleColor/bodyColor '#e6edf3', label callback formats as currency with 2 decimals
   - Store as historicalChart = new Chart(...)

5. `selectDateRange(range)` method:
   - Set `this.dateRange = range`
   - Call `this.renderHistoricalChart()`

6. `async triggerBackfill()` method:
   - Set `this.backfillStatus = 'loading'`
   - Fetch `api.php?action=backfill` (this will take a while -- many Yahoo API calls)
   - On success, set `this.backfillStatus = 'done'` and show toast with result message
   - Reload analytics data: `await this.loadAnalyticsData()`
   - On error, set `this.backfillStatus = null` and show error toast
